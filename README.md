Descrição:
Jogo para dois jogadores no mesmo computador, feito em Python com interface gráfica (tkinter); 
Vence quem conectar quatro fichas primeiro, na horizontal, vertical ou diagonal.             
Contém:
Tabuleiro de 7 colunas x 6 linhas;
Botões acima das colunas;
Colunas clicáveis; 
Cores diferentes para cada jogador (vermelho e amarelo na versão principal e verde e rosa na versão alternativa);
Indicador do jogador da vez;
Gravidade;
Validação de coluna cheia;
Detecção de vitória (4 em linha, todas as direções), com destaque nas fichas vencedoras;
Detecção de empate (tabuleiro cheio);
Botão "Reiniciar Jogo"
